WA Voice File Sender — Settings

These only matter for the optional auto-press convenience feature (automatically pressing WhatsApp's mic button for you). If WhatsApp Web changes its page layout and the button stops being found automatically, update the selectors below — or just turn auto-press off and press the mic button yourself, which always works regardless of these settings.

To find the right selector if auto-press stops working: right-click WhatsApp's mic button in the chat box → Inspect, note an attribute that uniquely identifies it (e.g. data-icon or aria-label), and add a selector like span[data-icon="ptt"] here.

This pauses the in-progress recording — it never sends automatically. You still press WhatsApp's send button yourself when ready.
